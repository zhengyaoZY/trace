# 寻迹 Android 0.3.0

原生 Java Android 工程，支持 Android 8.0+（API 26），面向 Android 15（API 35）。保留青绿色扁平界面、线性图标与离线矢量插画。

## 页面与数据

- **人文**：全部、历史、美食。首版提供雷峰塔、拱宸桥、河坊街风味。
- **自然**：全部、政府管理景区、自驾路线、徒步路线。提供西湖、西湖外围自驾示意、九溪徒步示意。
- **我的**：仅展示应用使用指南、分类、定位与隐私、数据边界及版本文档，无个人资料和统计功能。

前两个板块以当前位置展示地图，分类同步筛选标记和卡片。点标记选中并滚动到卡片，点“查看详情”阅读；点卡片空白处聚焦地图。进入板块默认回到当前位置，从详情返回保留分类、列表位置和地图视野。分类可横向滚动。

内容按探索位置周围 **50 公里**筛选。仅杭州内置内容；其他地区显示真实坐标对应的地图及“附近暂无示例内容”，可主动选择“查看杭州示例”。示例区域始终明确标注，不会将杭州冒充手机所在地。“◎ 定位”可回到手机当前位置。

景区管理信息字段包含管理单位和官方来源链接。西湖条目记录杭州西湖风景名胜区管理委员会及其政府官网 `https://westlake.hangzhou.gov.cn/`；本次云环境访问官网返回 503，未核验实时公告和开放情况。出行前应自行核对最新信息。

路线仅是参考点连成的**静态示意**，并非实测轨迹，不保证连线对应可通行道路；距离按 WGS84 坐标折线估算，不等于实际行程距离。详情提供虚线、起终点及途经点，不提供实时导航、路况、偏航、海拔或难度评定。美食条目为文化介绍，不提供实时商户推荐。

## 定位与隐私

首次进入人文或自然时申请**仅使用期间**的精确/大致位置权限；只授权大致位置也能使用。使用系统 LocationManager，无 Google Play Services 或定位服务 API Key 依赖。网络定位提供方可用性取决于设备。只获取一次前台定位结果，两个板块共享结果，缓存两分钟；取消页面或进入后台时停止请求，不申请后台权限，不保存位置历史，不上传到业务后台。

定位权限拒绝、系统定位关闭、提供方不可用或 15 秒未返回结果时，显示原因及“杭州示例区域”；可重试或打开系统定位/应用权限设置。永久拒绝权限后通过“应用权限”自行开启。无定位权限仍可浏览全部示例。

地图使用 osmdroid 6.1.20 和 OpenStreetMap HTTPS 瓦片，无地图密钥。瓦片服务会收到网络请求，可据瓦片推断所浏览区域。遵守其使用政策，不批量下载/预取；保留贡献者及 ODbL 署名。文字与插画内置，可离线使用；底图需联网或依赖系统缓存。无登录、无业务后台、无存储权限。

## 下载与安装

从仓库根目录 `downloads/trace-android-debug.apk` 下载原始 APK，在 Android 手机允许浏览器安装未知应用后打开安装。**不能安装到 iPhone。**仓库内 APK 沿用前版调试签名，可覆盖安装；其他机器或 CI 生成的调试包可能具有不同签名，冲突时需先卸载旧版。无需开发者会员，无 iOS 免费签名的七天限制。本包供个人试用；正式分发应安全保存长期 Release 签名，不提交私钥或密码。

也可登录 GitHub，在 **Android APK** 工作流下载 `trace-android-debug` 工件并解压安装。

## 开发与验证

Android Studio 打开 `android/`，安装 JDK 17/21、SDK Platform 35 和 Build Tools 35.0.0。Gradle Wrapper 固定 8.11.1，AGP 固定 8.9.1；SDK 路径由 IDE 的 `local.properties` 或 `ANDROID_HOME` 配置。

```sh
./gradlew assembleDebug lintDebug testDebugUnitTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
# 已启动模拟器或连接真机后，运行测试并导出截图：
./scripts/smoke.sh
```

JUnit 覆盖五类数据、50 公里筛选、定位状态、显式示例区域和路线距离。Espresso 通过可注入 LocationSource 模拟杭州、杭州之外、权限拒绝、定位关闭和超时；验证分类、地图点选、详情返回、路线折线和文档。测试数据不写入正式 APK，不代表验证了真实手机定位信号。GitHub Actions 构建 APK、运行 Lint/JUnit，并在 Android 15 模拟器执行 UI 测试、导出截图。

真机额外检查：首次定位授权、仅大致位置、拒绝与永久拒绝、关闭/恢复系统定位、室内超时、后台停止、返回前台、无网络阅读。UI 额外检查窄屏、大字体与旋转屏幕。
