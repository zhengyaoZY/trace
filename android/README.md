# 寻迹 Android 0.4.0 — 百度地图接入预览

原生 Java，Android 8.0+，SDK Platform 35，青绿色扁平界面。**当前仓库 APK 未配置百度 AK：可阅读本地示例和文档，真实百度地图与在线检索尚未验证，不能视为已完成线上接入。**

## 功能与边界

- 人文：全部、历史、美食；自然：全部、自然景区、自驾路线、徒步路线；我的：应用说明。
- 定位中心固定为手机位置，检索半径 **1000 米**。初始视野按屏幕尺寸适配以完整显示半径范围，手势只改变视野。定位按钮更新中心并刷新检索，不自动随拖动发请求。
- 地图和 POI 检索直接使用百度 Android Map/Search/Util **9.0.0**，没有代理、业务后台、账号或服务端 AK。
- 自定义景点覆盖物为 **14dp 中性等大圆点**，透明点击区域 44dp，无名称、序号；选中加描边，不放大。底图保留道路地名及百度署名。卡片仍显示名称和来源，点击联动保留。
- **本版不实现热度大小变化**：已检查 SDK 9.0.0 的 PoiInfo/PoiDetailInfo，没有官方榜单排名或近七天热度字段；不将评分、评论量、收藏量或搜索顺序冒充热度。官方 Web API 3.0 的相关字段不代表 Android SDK 支持；本次不调用 Web API。
- 分类关键词为检索偏好，不是官方认证。历史搜索文物古迹/历史建筑/博物馆，美食搜索餐饮，自然景区搜索自然风光/风景区/公园。未返回明确标签的混合人文结果标为“人文地点”。
- SDK 分页最多 5 页，每页容量 20；收到的结果按 UID 去重、严格一公里过滤、按距离排序，最多展示 100 条。不承诺覆盖所有附近地点。同一 BD-09 位置及分类缓存五分钟；取消页面或切换分类丢弃旧响应。失败时明确区分鉴权、配额和网络问题，不自动改用示例冒充在线数据。
- 百度实时 POI 标为“百度周边”，缺少介绍显示“暂无介绍”。本地杭州内容标为“本地示例”，只有主动进入示例模式或定位失败时展示；仍严格限制一公里，不自动扩大范围。
- 自驾/徒步继续是静态示例路线，按起点是否在一公里内筛选。自然“全部”可合并附近本地示例路线；路线卡片始终注明“非导航”。路线详情优先展示虚线与无序号途经点。不是百度导航规划或实测轨迹，不保证连线对应通行道路，距离只按参考点估算。

## 开通百度地图

1. 在 [百度地图开放平台控制台](https://lbsyun.baidu.com/apiconsole/key) 创建 **Android SDK 类型** AK，开通地图与 POI 检索，核对账户配额与使用授权。
2. 绑定包名 `com.zhengyaozy.trace`，以及用于安装包的签名 SHA-1。当前仓库 APK 签名是：

```text
AA:0E:47:B6:82:9F:79:50:60:36:0A:E6:ED:A5:C4:A8:92:34:85:F0
```

3. 在本目录创建被 Git 忽略的 `baidu.properties`：

```properties
BAIDU_MAP_AK=在本地安全填写你的Android类型AK
```

也可以给构建进程设置 `BAIDU_MAP_AK` 环境变量（优先于文件）。CI 从同名 GitHub Actions Secret 读取。**不要在聊天、源码或日志中粘贴真实 AK。**SDK AK 必须进入 APK 的 Manifest，是受包名/签名约束的客户端凭据，不是可藏在手机中的服务端秘密；应限制服务范围及配额。

4. 首次启动先阅读百度 SDK 使用说明并同意，再单独授权前台定位。真实鉴权通过后才进行周边查询。未配置 AK、鉴权失败及配额不足都不会被示例数据掩盖。
5. 使用相同签名生成新包，安装到真机核验地图、坐标及真实检索。Android Studio/其他 CI 机器生成的 debug.keystore 通常不同，必须绑定对应 SHA-1；仅填写本页指纹不能授权其他签名。默认 CI 的模拟场景不代表其 APK 已通过百度线上鉴权。

官方参考：[注册及 AK](https://lbs.baidu.com/docs/guide?title=android-guide/create-project/ak)、[POI 检索](https://lbs.baidu.com/docs/android?title=androidsdk/guide/search/poi)、[隐私政策](https://lbs.baidu.com/index.php?title=openprivacy)。当前没有 AK，因此没有执行付费请求、真实 SDK 鉴权或实际周边 POI 验收。

## 定位、坐标与隐私

沿用系统 LocationManager，不依赖 Google Play Services 或额外百度定位组件。首次获取手机位置申请精确/大致位置，支持仅大致授权；只获取前台单次结果并缓存两分钟。拒绝、关闭或超时十五秒会标注原因并显示“杭州示例区域”，不会将杭州冒充当前坐标。没有后台定位、不持久化位置历史、不上传业务后台。查询结果仅在进程内缓存，有效期五分钟，最多 32 组，退出进程后消失。

百度 SDK 使用同意与系统定位授权分开：未同意前不初始化百度 SDK、也不请求位置；暂不使用仍可看文档和本地文本。SDK 同意记录在本机，可在 Android 系统设置清除应用数据后重新选择。SDK 启用后会按其隐私政策向百度处理位置与必要设备信息以提供地图、检索服务；无本应用后台。没有 AK 时同样不初始化 SDK。

系统和本地路线坐标是 WGS84；进入百度前使用 SDK 转为 BD-09。在线 POI、保存的地图视野带坐标类型，BD-09 不重复转换。SDK 坐标转换和真实地图位置尚需配置 AK 后真机复验。

## 构建、下载与验证

安装 JDK 17/21、Android SDK Platform 35、Build Tools 35.0.0。Android Studio 打开本目录。Gradle Wrapper 为 8.11.1，AGP 为 8.9.1，SDK 路径由 `local.properties` 或 `ANDROID_HOME` 提供。

```sh
./gradlew assembleDebug lintDebug testDebugUnitTest assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
# 连接设备/启动模拟器后运行 UI 测试并取回截图：
./scripts/smoke.sh
```

仓库 `downloads/trace-android-debug.apk` 是同签名的 0.4.0 接入预览包，未配置 AK。下载原始 APK 后在 Android 手机允许安装未知应用即可，可覆盖前版；不能安装到 iPhone。APK 含 arm64-v8a、armeabi-v7a、x86_64 原生库，体积明显大于之前版本。源码重新构建可能使用不同签名，冲突时先卸载旧版或配置相同签名；正式发布应保管长期 Release 私钥，不提交到 Git。

JUnit 覆盖一公里边界、去重/排序/上限、五分钟缓存、刷新、旧响应丢弃、错误状态和坐标类型转换规则。Espresso 注入的 POI 和地图仅存在于 androidTest，画面明确写“测试地图 · 非百度底图”；覆盖圆点尺寸和点击、卡片、详情恢复、固定检索中心、错误重试、同意拒绝及缺少 AK。GitHub Actions 分别以 1.0/1.3 字体运行，**模拟测试通过不能代表真实百度服务可用**。

配置 AK 后必须另做真机验收：同意前无 SDK 请求、鉴权、精确/大致定位、坐标无偏移、一公里真实 POI、断网/配额提示、圆点命中、背景停止及百度标识。没有有效 AK 时这些仍是外部前提，不以通过的模拟测试替代。
