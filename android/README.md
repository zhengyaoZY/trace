# 寻迹 Android 0.5.0 — 后端接口接入预览

Android 8.0+，Java，青绿色扁平 UI。**当前仓库 APK 未配置公网 API 地址或百度 Android AK，后端也未配置真实服务端 AK；不能视为真实地图、POI 和指标已可用。**可浏览本地示例和文档。

## 架构与行为

- 人文：历史、美食；自然：自然景区、自驾路线、徒步路线；我的：应用文档。
- `Android WGS84定位 → 寻迹 HTTP API → 百度坐标转换与地点检索3.0 → 服务端清洗/计算 → Android展示`。底图单独使用百度 Map/Util SDK 9.0.0；客户端不再使用百度 Search SDK，不保存服务端 AK。
- 手机位置为固定中心、半径 1000 米。手势只改变视野；定位按钮刷新中心和数据。取消请求、迟到响应、分类与详情返回状态均保留。
- 后端控制分类、分页、UID 去重、距离过滤、缓存及排序；Android 保留后端顺序，以服务端 `expiresAt` 控制缓存，不再延长有效期或把 GPS 与 BD09 混算距离。真实 POI 为 BD09，地图不重复转换；本地路线仍为 GPS 示例。
- 官方排名和七天热度各占 50%，一项缺失则使用另一项，全缺失为 14dp 中性圆点。不用评分、评论量或搜索顺序冒充热度。综合指数由本应用计算，并非百度官方总榜。
- 圆点直径 `sqrt(14² + score*(40²-14²)) dp`，点击区至少44dp；无名称、无序号，选中加描边，不放大。保留卡片联动和原始指标说明。
- 自驾/徒步为本地静态示意，按起点一公里范围筛选，附在自然列表后，最多显示一百条内容，不参与官方热度计算。路线非导航，不保证连线对应可通行道路。
- 地图与后端的可用性独立：缺少地图 AK 时仍可请求已配置的后端并展示卡片；缺少后端地址、鉴权/配额/限流/网络失败时明确提示，不以示例冒充真实数据。

## 两类配置

### Android 地图 AK

在百度开放平台创建 Android SDK 类型 AK，绑定包名 `com.zhengyaozy.trace` 与当前 APK 签名：

```text
AA:0E:47:B6:82:9F:79:50:60:36:0A:E6:ED:A5:C4:A8:92:34:85:F0
```

在忽略提交的 `android/baidu.properties` 中填写 `BAIDU_MAP_AK=…`，或给构建进程设置同名环境变量。CI 使用 GitHub Actions Secret `BAIDU_MAP_AK`。此客户端凭据会进入 APK，须限制服务与配额，不能当作服务端秘密。

### 本应用 API 地址

在忽略提交的 `android/api.properties` 中填写：

```properties
# Android 模拟器访问电脑上的本地服务，仅 Debug 允许
API_BASE_URL=http://10.0.2.2:3000
```

或设置构建环境变量 `API_BASE_URL`（优先）。CI 使用同名仓库 Variable。协议细节与服务端启动见 [后端文档](../server/README.md)。API 接口不接受客户端传递百度 AK。

Debug 只允许 localhost、模拟器宿主地址和私有 IPv4 网段的 HTTP；其他地址必须 HTTPS。Release 全面禁止 HTTP，Manifest 也禁用明文。API 地址不能包含用户名、密码、查询参数或 fragment，**不要把密钥放在 URL**。默认地址为空，不会偷偷连接第三方服务。

真机联调使用电脑局域网 IP，而非10.0.2.2；后端需绑定可信局域网接口并允许防火墙访问。公开部署不在本次范围，应使用域名和 HTTPS 网关。`BAIDU_SERVER_AK` 仅由后端读取，绝不能放进 Android 配置或 APK。

## 隐私与定位

隐私同意升级为第2版，老版本 SDK 同意不能授权新后端接收位置：升级首次使用会重新说明位置发送到寻迹后端、再转发百度的用途。未同意不初始化 SDK、不请求定位和后端；暂不使用仍可阅读文档和本地示例。

系统 LocationManager 获取一次前台定位，支持大致位置，缓存两分钟；进入后台取消请求，不保存轨迹、不申请后台定位。拒绝、关闭或超时十五秒时使用明确标注的杭州示例区域。百度 SDK 的必要设备信息与地图请求、后端短时内存缓存均在应用文档说明。

## 构建、安装和验证

JDK17/21、SDK35、Build Tools35.0.0、Gradle8.11.1、AGP8.9.1。

```sh
cd android
./gradlew assembleDebug lintDebug testDebugUnitTest assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
./scripts/smoke.sh
```

仓库 `downloads/trace-android-debug.apk` 是同签名0.5.0预览包，可覆盖前版，不能安装到 iPhone。含三个CPU架构，体积约80MiB。无公网服务配置和AK时只能体验本地文本及说明，不能使用真实地图/周边数据。

JUnit 覆盖坐标类型、客户端不重排服务端结果、缓存不过期延长、取消与迟到响应、圆点面积单调性。模拟器 UI 使用明确标注的测试地图/POI，验证大小、联动、详情状态、隐私拒绝、配置缺失、后台取消、错误重试；另用真实回环 HTTP 测试服务验证 POST/WGS84、响应BD09/指标/缓存到期、错误及协议约束。CI 分别用1.0与1.3字体运行，不代表真实百度验收。

配置后需要真机确认：升级后重新同意、真实地图鉴权、精确/大致定位、坐标无偏移、一公里POI、官方指标实际返回和格式、缺失指标、重叠圆点点击、断网/限流、后台停止及百度署名。禁止把模拟验证当成真实数据已接通。
